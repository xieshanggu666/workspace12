# 🔭 天文观测计划生成器

给定**观测地点**与**日期**，按本地恒星时整夜推算各目标的地平高度变化，
联合扣除**月光、天文暮光、山头遮挡角**与赤道仪时角极限，筛出连续可观测窗口，
并自动排出拍摄顺序；正确处理**过中天翻转（meridian flip）**与**单次曝光时长分组**。
高度曲线、极投影星图与计划清单**同步联动**，可在界面上直接拖拽手工调序后重新排程。

坐标换算与星历**全部自行实现**（仅依赖 numpy，无 ephem/astropy）：
GMST、儒略日、赤道↔地平变换、岁差章动、太阳（Meeus ch.25）、
月球（Meeus ch.47 周期项 + 站心视差）、Bennett 大气折射。

## 快速开始

```bash
pip install -r requirements.txt

# Web 界面(默认 http://127.0.0.1:8000)
python -m astro_planner.server
#   可选 --host 0.0.0.0 --port 8000

# 命令行直接出计划
python -m astro_planner.cli --site 兴隆观测站 --date 2025-10-15 --tz 8

# 自定义地点 / 平坦地平线 / 导出 JSON
python -m astro_planner.cli --lat 30.1 --lon 121.1 --elev 50 \
    --date 2025-12-01 --horizon flat --json > plan.json

# 整夜演示(终端打印并生成 webapp/demo.json)
python examples/demo_night.py
```

内置预设观测点：兴隆、德令哈、冷湖、丽江高美古、怀柔、阿塔卡马（南半球）；
内置 16 个常用深空目标星表（J2000，可在页面表格中直接编辑增删参数）。

## 界面功能

- **高度曲线图**：每个目标整夜高度曲线，粗线段=当前约束下可拍摄窗口，
  ▲=过中天；底色区分民用/航海/天文暮光；另绘太阳、月亮与全局最低高度线；
  时间游标可拖动或播放动画。
- **极投影星图**：与游标时刻同步，显示各目标瞬时方位/高度、月相、
  地形遮挡（棕色填充），高亮当前可拍目标。
- **计划清单**：按时间列出 slew/导星 → 中天前曝光 → ⟲过中天翻转 → 中天后曝光，
  标注张数、单张时长、中天前/后；**拖拽目标块即可手工调序**，松手自动重算；
  “恢复自动排序”回到按中天时刻 + 优先级的自动结果。
- 顶部表单可改观测点、日期、时区、地形、全局最低高度、赤道仪时角极限、
  网格步长、slew 时间、翻转耗时；目标表可改每个目标的单张时长、张数、
  最低高度、是否避月光及满月月距要求。

## 计算流程（`astro_planner/`）

| 模块 | 内容 |
|---|---|
| `timeutils.py` | 儒略日（Meeus 7.1）、GMST/LST（12.4 角度制）、夜间 12:00→次日12:00 等间隔网格 |
| `coordinates.py` | 赤道(HA,Dec)↔地平(Az,Alt)、角距、岁差（21.6）、黄赤交角+章动、黄道→赤道、Bennett 折射 |
| `sunmoon.py` | 太阳低精度历表（ch.25）、月球 ELP 截简式（ch.47 表 A/B/C）、三角视差站心修正、月相照亮比例 |
| `horizon.py` | 方位角→遮挡高度的循环折线，线性插值；平坦/山地预设 |
| `ephemeris.py` | 整夜逐点高度/方位/时角、暮光时刻、月距、五重掩码与连续窗口提取 |
| `scheduler.py` | 自动排序、围绕中天的曝光分组与翻转块、slew/翻转耗时、手工 order |
| `planner.py` | 门面 + 地点预设 |
| `server.py` / `cli.py` | 标准库零依赖 HTTP 服务 / 命令行 |

### 可观测性判定（逐时间点）

```
可拍 = 天文暗夜 (太阳 < -18°)
       ∧ 视高度 ≥ max(目标最低高度, 全局最低高度)
       ∧ 几何高度 > 该方位山头遮挡角 + 安全裕量
       ∧ |时角| ≤ 赤道仪时角极限
       ∧ (窄带目标 或 月心角距 ≥ 随月相插值的要求角距)
```

月距要求在新月（默认 15°）到满月（默认 60°，再与目标自身
`moon_sep` 取小值）之间按月球照亮比例线性插值；窄带/Hα 目标可勾选
“不避月光”。

### 过中天翻转排程

对包含中天的窗口，以中天时刻为锚，预留
`[中天前曝光组] + 翻转(默认3分钟, 对称分布于中天前后) + 中天后曝光组`，
尽量在两侧平分计划张数；轮到时若已贴近/越过中天则退化为纯西侧安排，
不插入无意义翻转。排在前面的西落目标会自动为后续中天目标让路
（保留至少一张中天前曝光 + 翻转裕量）。单次曝光若超过窗口剩余时长，
按可容纳张数截断并在“注意事项”中报告 `完成 n/N 张`。

## 说明与精度

- 太阳/月球为 Meeus 低精度截简式，位置误差约 0.01–0.03°，
  月距误差百公里量级，对观测排程完全足够；未含行星摄动小项与 ΔT（影响 < 0.01°）。
- 星表坐标按 J2000 给出，计算时岁差到观测日期，章动取主项。
- 时间以**地方时刻小数小时**表示并允许超过 24（即次日凌晨，如 27:30 = 次日 03:30）。
